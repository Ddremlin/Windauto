# Windauto

Мобильное веб-приложение для приёмки автомобилей в кузовной ремонт и покраску.

- Госномер (проверка по польскому формату) и VIN (17 символов, без I/O/Q, контрольная цифра)
- Развёртка кузова: нажатие на элемент → виды работ галочками, элемент закрашивается цветом работы
  (несколько работ — полосами)
- Расшифровка VIN без интернета (марка, год) и распознавание техпаспорта, VIN и номера по фото (через сервер)
- Состояние при приёмке: топливо, ключи, комплектность, вещи в салоне, повреждения «уже было»
- Смета: работы и запчасти по элементам, скидка, нетто / VAT / брутто
- Подпись клиента и мастера пальцем на экране, согласие RODO; PDF листа приёмки и акта выдачи (фото до/после)
- Номера заказов 2026/0001, статусы (принят → в работе → ждём запчасти → готов → выдан), ответственный, срок
- Сообщение клиенту «машина готова» в WhatsApp / SMS / e-mail, статистика по месяцам и видам работ
- Данные хранятся на устройстве (IndexedDB); общая база для сотрудников — `server/`
  (правки разных полей с разных телефонов объединяются, история изменений)

## Запуск

```bash
npm install
npm run dev        # разработка, http://<ip>:5173
npm run build      # сборка в dist/
npm run preview    # просмотр сборки, http://<ip>:4173
npm test           # тесты (Node 22.6+): слияние, VIN, смета, сервер целиком
```

Справочники: виды работ, повреждения, комплектность — `src/works.ts`, элементы кузова — `src/body.ts`, проверки — `src/validate.ts`,
коды производителей VIN — `src/vin.ts`, текст RODO по умолчанию — `src/rodo.ts`.
Слияние правок — `src/merge.ts` и его копия `server/merge.mjs` (менять вместе).

## Публикация

Веб-версия: https://app.dmerlinauto.vip — на одном адресе с сервером синхронизации (Caddy отдаёт папку
`/opt/windauto/web`, API — `/api`, `/auth`, `/legal`). Выкладка:

```
npm run build && rsync -a --delete dist/ root@95.216.219.8:/opt/windauto/web/
```

Прежний адрес https://ddremlin.github.io/Windauto/ — страница переезда (`pages-redirect/index.html`):
стирает токен входа и уводит на новый адрес, а если в браузере остались неотправленные изменения —
даёт дослать их из прежней версии (`old/`). Публикуется при каждом push в `main`
(GitHub Actions, `.github/workflows/deploy.yml`).
