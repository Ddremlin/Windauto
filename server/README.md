# Сервер Windauto

Общая база заказов и фото для нескольких сотрудников. Node.js 24 + SQLite (единственная зависимость — Anthropic SDK для распознавания);
HTTPS через Caddy (сертификат Let's Encrypt выпускается сам).

## Установка на VPS

Нужен VPS с Ubuntu 22.04/24.04 или Debian 12 (1 ядро, 1 ГБ RAM достаточно), открытые порты 80 и 443.

```bash
scp -r server root@<IP>:/opt/windauto
ssh root@<IP> 'bash /opt/windauto/install.sh'
```

Скрипт поставит Docker, запустит сервер и выведет адрес (`https://<IP>.sslip.io`) и пароль администратора.
Свой домен: `bash install.sh api.example.pl` (DNS-запись A должна указывать на IP сервера).

## В приложении

Настройки → «Общая база» → адрес сервера, логин `admin`, пароль из вывода установки.
Администратор добавляет сотрудников там же, в разделе «Сотрудники».

## Распознавание VIN, номера и техпаспорта по фото

Кнопка камеры у полей VIN и номера и кнопка «Техпаспорт» отправляют снимок на сервер, сервер — в Claude (Anthropic API).
Включается ключом в `/opt/windauto/.env`:

```
ANTHROPIC_API_KEY=sk-ant-...
```

затем `docker compose up -d`. Модель по умолчанию `claude-opus-5-5`, сменить — `AI_MODEL=...`.

## Обслуживание

```bash
cd /opt/windauto
docker compose logs -f api        # журнал
docker compose up -d --build      # обновление после замены server.mjs / merge.mjs
./backup.sh                       # резервная копия вручную (автоматически — каждую ночь в 03:30)
```

Данные: `data/windauto.db` (база, история изменений, счётчики номеров), `data/photos/` (фото) и `data/videos/` (круговые видео приёмки).
Ночная копия видео не включает — они большие; копируйте `data/videos/` отдельно (например, `rsync` на другой диск).
Номера заказов единые на сервер: `2026/0001`, счётчик по годам. Блокировка подбора пароля (10 попыток / 15 минут) хранится в базе и переживает перезапуск. Копии: `backups/`, хранятся 30 последних.
Восстановление: остановить (`docker compose down`), распаковать архив в `data/`
(`backup.db` переименовать в `windauto.db`), запустить снова.

## API

| Метод | Путь | Назначение |
|---|---|---|
| POST | /api/login | вход, выдаёт токен |
| GET | /api/sync?since=N | изменения новее N |
| POST | /api/sync | отправка изменений; если заказ меняли параллельно — слияние по полям (`_ft`), результат в `merged`; там же номер для новых заказов |
| GET | /api/events | SSE-уведомления об изменениях |
| PUT/GET | /api/photos/:id | фото |
| PUT/GET | /api/videos/:id.mp4 | круговое видео приёмки (до 300 МБ, GET поддерживает Range) |
| POST | /api/recognize | `{kind: 'vin'\|'plate'\|'doc', image: base64 JPEG}` → `{value, country?, confident}`, для doc — `{plate, vin, make, model, year, owner, confident}` |
| GET | /api/orders/:id/history | история изменений заказа (кто, когда, какие поля) |
| GET | /api/staff | сотрудники для выбора ответственного (все пользователи) |
| GET/POST/PATCH/DELETE | /api/users | сотрудники (только администратор) |
